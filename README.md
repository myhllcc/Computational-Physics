# Computational Physics

Numerical computing coursework by Yunhao Mo, University of Manchester (2020-2021) and Imperial College London (2023).

- [Monte Carlo neutron transport](undergraduate/monte-carlo-neutron-transport/) — random walks, sampling and statistical uncertainty.
- [Damped and forced oscillator](undergraduate/damped-forced-oscillator/) — numerical integration and error analysis.
- [Bouncing ball](undergraduate/bouncing-ball/) — introductory Python simulation.
- [Ising model](postgraduate/ising-metropolis/) — MATLAB Metropolis simulation.
- [Mathematica scientific computing](postgraduate/mathematica-scientific-computing/) — symbolic and numerical exercises.

Open the relevant project for code, reports and usage. See [dependencies](DEPENDENCIES.md).
